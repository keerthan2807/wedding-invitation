MEMORIES PHOTOS
===============
Drop your photos in this folder (jpg, jpeg, png, webp, avif, gif).
They appear automatically in the "Moments Frozen in Time" stack on the events page,
ordered by file name — e.g. 01.jpg, 02.jpg, 03.jpg ...

Tips
- Keep each photo under ~500 KB (roughly 1200px on the long side) so the page stays fast on phones.
- With no photos here, the frame shows "Coming Soon".
- After adding photos, rebuild/redeploy (npm run build); `npm run dev` picks them up live.
